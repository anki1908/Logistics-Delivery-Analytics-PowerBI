# Logistics & Delivery Analytics Dashboard | Power BI

## 📊 Project Overview

The **Logistics & Delivery Analytics Dashboard** is an interactive Power BI project designed to analyze delivery operations, logistics costs, service-level performance, profitability, and customer experience.

The dashboard uses a dataset of **1,000 logistics transactions** to identify delivery delays, evaluate delivery partner performance, analyze transportation costs, and understand how factors such as distance, priority, warehouse, and customer type affect operational performance.

The project demonstrates the use of **Power Query, DAX, data modeling, interactive visualizations, KPI analysis, and business-oriented dashboard design**.

## 🎯 Business Objectives

The dashboard was developed to answer key logistics and operational questions:

- How efficiently are orders being delivered?
- What percentage of deliveries are completed on time?
- Which delivery partners have the best SLA performance?
- Which cities and warehouses experience higher delivery delays?
- Does delivery distance affect delay and logistics cost?
- Which delivery partners are more cost-efficient?
- How much does logistics cost contribute to sales?
- Which product categories generate higher profit?
- How do delivery performance and delays affect customer ratings?
- What are the return and cancellation rates?

The project uses a **synthetic logistics dataset containing 1,000 transactions** created for learning and portfolio development.

The dataset includes information about:

- Orders
- Warehouses
- Destination cities
- Products
- Customers
- Delivery partners
- Distance
- Delivery time
- Logistics costs
- Order status
- Customer ratings
- Profitability

> **Note:** The dataset is simulated and is intended for educational and portfolio purposes. Financial and operational values should not be interpreted as real company data.
